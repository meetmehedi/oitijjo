# 🏛️ ঐতিহ্য (Oitijjo) — Traditional Bangladeshi Craft Marketplace

[![Next.js](https://img.shields.io/badge/Next.js-16-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![React](https://img.shields.io/badge/React-19-blue?style=for-the-badge&logo=react)](https://react.dev/)
[![UNESCO](https://img.shields.io/badge/Cultural_Heritage-Bangladesh-red?style=for-the-badge)](https://ich.unesco.org/)

**ঐতিজ্জ্বো (Oitijjo)** হলো বাংলাদেশের প্রাচীন লোকঐতিহ্য ও হস্তশিল্পকে সংরক্ষণ এবং গ্রামীণ প্রান্তিক কারিগরদের ডিজিটাল বাণিজ্যের মাধ্যমে সরাসরি ক্রেতাদের সাথে যুক্ত করার একটি প্ল্যাটফর্ম।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

- **🛍️ সরাসরি কারিগর-ক্রেতা সংযোগ:** মধ্যস্থভোগী ছাড়া ন্যায্যমূল্যে আসল হস্তশিল্প ক্রয়।
- **🛡️ এসক্রো (Escrow) পেমেন্ট গেটওয়ে:** bKash, Nagad এবং ক্যাশ অন ডেলিভারি (পণ্য পেয়ে সন্তুষ্ট হওয়ার পর কারিগরের কাছে অর্থ ছাড়)।
- **📜 "কারিগরের গল্প" (Artisan Stories):** প্রতিটি পণ্যের পেছনে কারিগরের অভিজ্ঞতা, ঐতিহ্য ও জীবনের গল্প।
- **🔍 ইন্টেলিজেন্ট শপ ক্যাটালগ:** ক্যাটাগরি (নকশিকাঁথা, তাঁত শাড়ি, মৃৎশিল্প, শীতলপাটি) ও অঞ্চলভিত্তিক লাইভ ফিল্টারিং ও সর্টিং।
- **📝 ৫-ধাপের কারিগর অনবোর্ডিং:** জাতীয় পরিচয়পত্র (NID) ও মোবাইল OTP যাচাইকরণ।
- **💬 সরাসরি কারিগর চ্যাট/মেসেজিং:** বিশেষ কাস্টম অর্ডারের জন্য কারিগরের সাথে সরাসরি যোগাযোগ।
- **🎨 রয়্যাল ভিন্টেজ ডিজাইন থিম:** পার্চমেন্ট টেক্সচার, গোল্ড অ্যাকসেন্ট ও ক্লাসিক বাংলা টাইপোগ্রাফি।

## 🪡 সংরক্ষিত ঐতিহ্যবাহী কারুশিল্প (Craft Categories)

1. **নকশিকাঁথা (Nakshi Kantha):** ৫০০+ বছরের প্রাচীন গ্রামীণ নারীদের নিপুণ সূচিশিল্প।
2. **তাঁত শিল্প (Tangail Tant Weaving):** ইউনেস্কো স্বীকৃত টাঙ্গাইল ও জামদানি মোটিফের হ্যান্ডলুম শাড়ি।
3. **মৃৎশিল্প (Pottery & Terracotta):** মহাস্থানগড় ও রায়েরবাজারের প্রাচীন পোড়ামাটির রূপ।
4. **শীতলপাটি (Shital Pati):** ইউনেস্কো স্বীকৃত সিলেটের প্রাকৃতিকভাবে শীতল পরিবেশবান্ধব পাটি।

## 🚀 লোকাল ডেভেলপমেন্ট সেটআপ (Local Setup)

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/meetmehedi/oitijjo.git
cd oitijjo/oitijjo-platform

# ২. ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ৩. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

ব্রাউজারে ওপেন করুন: **[http://localhost:3000](http://localhost:3000)**
